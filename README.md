# React To-Do List

A simple and responsive To-Do List application built with React.

## Features

- Add new tasks
- Edit existing tasks
- Delete tasks
- Mark tasks as completed
- Search tasks
- View task statistics
- Clear completed tasks
- Save tasks using Local Storage
- Responsive design for mobile and desktop

## Technologies Used

- React
- JavaScript
- HTML
- CSS
- Vite
- Local Storage
